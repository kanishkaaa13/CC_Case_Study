Cloud Service Models

Who manages what? The more the cloud provider manages, the less infrastructure overhead for developers.

IaaS (Infrastructure)

Virtual machines, raw storage, and networks on rent. You install and manage the operating system, Nginx server, and application stack.

AWS EC2 GCP Compute
Provider Manages ~30%

PaaS (Platform)

A ready platform to run your code directly. The cloud provider handles OS updates, scaling, load balancing, and security patches automatically.

GitHub Pages App Engine
Provider Manages ~70%

SaaS (Software)

Complete software delivered entirely through a web browser. Zero installation, zero infrastructure configuration, or maintenance.

Gmail Google Docs
Provider Manages 100%

Deployment Steps

Step-by-step workflow completed to publish this web application.

1
Write the Page
One single-file index.html combining structure, Tailwind CSS styling, and JavaScript logic.
2
Create GitHub Repository
A public repository named cloud-case-study hosted on GitHub.
3
Upload Code & Push
Commit index.html to main branch using Git CLI.
4
Enable GitHub Pages
Settings → Pages → Deploy from branch main / root.
5
Open Live URL
Access hosted web app live at https://username.github.io/cloud-case-study/.
6
Deploy on AWS EC2
Launch EC2 instance, authorize Security Group Port 80, install Nginx server, and copy index file.
.github/workflows/deploy.yml 
name: Cloud Deployment Pipeline (AWS/GCP)

on:
  push:
    branches: [ "main" ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v3

      - name: SSH Deploy to EC2
        uses: appleboy/ssh-action@v0.1.10
        with:
          host: ${{ secrets.EC2_HOST_IP }}
          username: ubuntu
          key: ${{ secrets.EC2_SSH_KEY }}
          script: |
            cd /var/www/html
            git pull origin main
            sudo systemctl restart nginx
